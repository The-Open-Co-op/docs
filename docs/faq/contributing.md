# Contributing

<details>
<summary>How can I contribute if I'm not a developer?</summary>

In many ways!

You can support the project via [Open Collective](https://opencollective.com/open-coop) — we don't currently have any funding so financial support is much appreciated and all expenses will be tracked openly so you can see where funds are spent.

You can submit feedback and questions about the demos — this will help us refine and improve the UI and UX.

You can tell other people about The Open Co-op and the PLANET project — the more members we can onboard the better placed we will be for launch.

You can propose ideas, or better still offer to lead, on developing the co-op and the PLANET project. When membership of The Co-op has grown sufficiently we will establish working groups for:

- **Governance** — evolving The Open Co-op's structure as membership grows
- **Product** — designing and building the apps
- **Outreach** — connecting with communities that could benefit from PLANET
- **Network** — recruiting recognisable names and movement leaders
- **Business** — refining the hosting model, funding strategy, and sustainability plan

If you have skills in any of these areas we would love to [hear from you](https://collab.open.coop/home/feedback) — and if anyone has experience of grant funding and time to search for and apply to suitable funds that would be a real help to the project.

</details>

<details>
<summary>How do I become a co-op member?</summary>

Just click Join us on [collab.open.coop](https://collab.open.coop/) and follow the onboarding.

</details>

<details>
<summary>Can I fund a specific feature?</summary>

Yes, this is absolutely part of the plan. We aim to set up a bounty system for PLANET so that any member of The Open Co-op can propose a new feature, which other members can debate and help refine, and price, so that funds can be crowdsourced and once the bounty is raised developers can apply to do the work. But at this early stage our main goal is to develop a working demo of all the core features of PLANET, so bounties may not be deployed until after we have a minimal viable product.

</details>
